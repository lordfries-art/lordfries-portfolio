Manage your projects, upload images, videos, sound and 3D models, then export a ready-to-publish LORDFRIES website.

This manager works locally on your computer. Changes are saved in this browser, not on GitHub. Export a website ZIP when you want to publish, and download a backup periodically so you do not lose your work if browser data is cleared.

PROJECT MEDIA

Each project can have multiple images, MP4/WebM videos, MP3/WAV audio files and GLB 3D objects. Drag-free ordering with arrow controls.

WEBSITE TEXT & DETAILS

Edit the words shown on your homepage, your contact details, profile links and artist photo. For headings, use a new line to set the line breaks. Use [accent]word[/accent] for orange text and [period].[/period] for small accent punctuation.

Changes save in this browser. Export to publish.
